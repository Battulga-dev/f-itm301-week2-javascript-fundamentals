# ITM301 - Week 2: JavaScript Fundamentals

## Тайлбар
Энэхүү repo нь ITM301 хичээлийн Week 2-ийн лабораторийн ажлуудыг агуулна. JavaScript-ийн үндсэн ойлголтууд болох хувьсагч, өгөгдлийн төрөл, нөхцөлт оператор зэргийг дадлагажуулсан.

## Хавтасны бүтэц
- `css/` - Хуудасны загварчлал (styling)
- `js/` - JavaScript дасгалын кодууд
- `index.html` - Үндсэн HTML файл
